# ศูนย์ข่าวสาร ม.5/4 โรงเรียนพรตพิทยพยัต ปีการศึกษา 2569

เว็บกลางของห้อง ม.5/4 แผนการเรียนวิศวกรรมและสถาปัตยกรรม สำหรับนักเรียนและผู้ปกครอง ภาคเรียนที่ 2/2569

**เปิดเว็บ:** https://watpolprot-cloud.github.io/prot-m54-2569/

ครูแจ้งข่าวในกลุ่ม LINE ตามปกติ และเก็บทุกประกาศไว้ที่นี่แยกเป็นหมวด เพื่อให้ย้อนดูได้โดยไม่ต้องเลื่อนแชต

- ข่าวด่วนและสิ่งที่ต้องทำ พร้อมนับวันถึงกำหนด
- บอร์ดข่าว 11 หมวด ค้นหาได้ทุกภาคเรียน และมีลิงก์ตรงของแต่ละข่าว
- ปฏิทินกิจกรรม ตารางเรียน และตารางการแต่งกาย
- ลิงก์เอกสาร บริการของโรงเรียน และคำถามที่พบบ่อยสำหรับผู้ปกครอง
- สมาชิกห้อง 40 คน กดรูปเพื่อดูแฟ้มผลงานรายคน ทั้งตำแหน่ง รางวัล งานเพื่อส่วนรวม และโครงงาน IS
- ภาพความทรงจำ 11 กิจกรรมของภาคเรียนที่ 1/2569
- ผู้ช่วยตอบคำถาม ม.5/4 (Gemini) ตอบจากข้อมูลบนเว็บนี้ รหัสเก็บไว้ฝั่ง Google Apps Script ไม่อยู่ในเว็บ

ครูที่ปรึกษา: ครูนพพล ภาณุสุวัฒน์ และครูศจินันท์ ตาตะนันทน์

เว็บนี้เป็นสาธารณะ จึงไม่มีข้อมูลส่วนบุคคลของนักเรียนและครอบครัว เช่น เบอร์โทร ที่อยู่ หรือผลการเรียนรายคน
